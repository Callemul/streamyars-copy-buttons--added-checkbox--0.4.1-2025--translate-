# DOM Snapshots Archive (Архів реальних HTML-дампів StreamYard)

У цій директорії зберігаються точні фрагменти HTML-коду, скопійовані з Chrome DevTools на реальному сайті StreamYard.

## Правило для ШІ та розробників:

1. **Перед зміною DOM-селекторів для StreamYard** — спершу перевір, чи є в цій папці
   снепшот потрібної зони. Якщо є — звірся з ним, перш ніж правити `SYH_CONFIG.SELECTORS`
   (`modules/config.ts`).
2. **Якщо снепшота нема** — не вигадуй структуру DOM. Зніми потрібний фрагмент HTML
   через Chrome DevTools (`Elements` → правий клік по вузлу → `Copy → Copy outerHTML`)
   і поклади його сюди файлом із описовою назвою.
3. **Нові зразки**: при виявленні нових елементів UI (модалок, кнопок, плашок) їх HTML-код
   додається сюди як новий snapshot, щоб наступна зміна вже могла на нього спертись.

## Список снепшотів:

Наразі в папці немає жодного знятого снепшота — нижче TODO-список зон, які варто
зняти першими, коли вони знадобляться для роботи над селекторами:

- `afk_dialog.html` — модальне вікно "Are you still there?" / "Stay in the studio" — **ще не знято**.
- `comments.html` — блок коментарів StreamYard — **ще не знято**.
- `banners.html` — блок банерів StreamYard — **ще не знято**.

Список поповнюється в міру появи реальних файлів; знятий снепшот прибирається з TODO
і лишається лише як пункт зі своєю назвою файла.
