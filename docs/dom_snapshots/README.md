# DOM Snapshots Archive (Архів реальних HTML-дампів StreamYard)

У цій директорії зберігаються точні фрагменти HTML-коду, скопійовані з Chrome DevTools на реальному сайті StreamYard.

## Золоте правило для ШІ та розробників:
1. **Жодної розробки наосліп**: Перед створенням або зміною DOM-селекторів для StreamYard, ШІ зобов'язаний звіритися з файлами у цій папці.
2. **Додавання нових зразків**: При виявленні нових елементів UI (модалок, кнопок, плашок) їх HTML-код додається сюди як новий snapshot.

## Список снепшотів:
- `afk_dialog.html` — реальний HTML-код модального вікна "Are you still there?" / "Stay in the studio" (заповнюється розробником).
- `comments.html` — HTML-структурний зразок блоку коментарів StreamYard.
- `banners.html` — HTML-структурний зразок блоку банерів StreamYard.
