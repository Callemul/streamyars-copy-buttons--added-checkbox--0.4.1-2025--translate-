# 💡 Ідеї на майбутнє: Інтеграція Google API (Gemini), класифікація живого потоку та розширені шаблони

Цей документ фіксує концептуальні ідеї та побажання користувача щодо подальшого розвитку розширення (версії v0.7+).

---

## 1. Підключення Google API (Gemini) для автоматичної категоризації коментарів під час ефіру
- **Проблема**: Під час прямого ефіру глядачі залишають десятки й сотні повідомлень у чаті YouTube/StreamYard одночасно. Оператору або ведучому важко миттєво визначити категорію кожного коментаря вручну.
- **Рішення**:
  - Можливість користувачу зберегти власний Google AI Studio (Gemini) API-ключ в опціях розширення (`chrome.storage`).
  - Фонова або напів-автоматична оцінка вхідних коментарів за допомогою легкої моделі (наприклад, Gemini Flash) для швидкої підказки категорії («Гаряче питання», «Питання по темі», «Особисте прохання про молитву», «Технічне зауваження»).
  - Візуальні кольорові бейджі або підказки поруч з коментарями, які допомагають ведучому миттєво орієнтуватися в прямому ефірі.

---

## 2. Жести та варіативність кліків миші для питань (ЛКМ, ПКМ, СКМ)
- **Концепція**: За аналогією з тим, як зараз працює копіювання молитовних коментарів (різні модифікатори та кнопки):
  - **ЛКМ**: Швидке стандартне копіювання питання для банера.
  - **ПКМ**: Відкриття контекстного міні-меню («Куди вставити: Ефір / Глядачі / Гаряче / Опарін / Молчанов»).
  - **СКМ (коліщатко)**: Спеціальний комбінований формат або миттєва відмітка як «Опрацьовано».

---

## 3. Спеціальний формат для диктора / ведучого ефіру
- **Вимога**: Залежно від обраної категорії питання формувати спеціальну текстову шапку, щоб диктор міг миттєво зрозуміти пріоритет під час читання з суфлера чи екрана.
- **Приклад формату для «Гарячого питання»**:
  ```text
  >>>>>Горяще питання<<<<<<
  Автор коментаря
  Сам текст коментаря
  ```
- **Приклад для уроку / ефіру**:
  ```text
  📺 ПИТАННЯ ЕФІРУ
  Автор коментаря
  Сам текст коментаря
  ```
- **Приклад для молитви**:
  ```text
  🙏 МОЛИТОВНЕ ПРОХАННЯ
  Автор коментаря
  Сам текст коментаря
  ```
