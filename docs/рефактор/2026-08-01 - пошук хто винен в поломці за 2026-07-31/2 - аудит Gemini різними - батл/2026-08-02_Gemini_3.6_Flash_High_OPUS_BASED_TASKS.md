## 🔴 HIGH — Критичні проблеми (Виправити терміново)

- [ ] **[H1] Memory leak — накопичення `document` click listeners у `studio_events.ts`**
  - **Файл:** [studio_events.ts](file:///d:/Chrome%20Extension/Время%20перемен.%20Chrome%20Extension/streamyars-copy-buttons%20(added%20checkbox)%200.6-2026.01.11/youtube/studio/studio_events.ts#L270-L280)
  - **Проблема:** У всередині `bindStudioCommentEvents()` додається `document.addEventListener('click', ...)` для кожної ітерації коментарів під час віртуального скролінгу.
  - **Рішення:** Винести listener за межі `bindStudioCommentEvents()` та реалізувати єдиний глобальний listener для закриття dropdown.

- [ ] **[H2] `getBrandFromLocalStorage()` без safe `try-catch` навколо `JSON.parse` у циклі**
  - **Файл:** [stats_tracker.ts](file:///d:/Chrome%20Extension/Время%20перемен.%20Chrome%20Extension/streamyars-copy-buttons%20(added%20checkbox)%200.6-2026.01.11/modules/stats_tracker.ts#L290-L310)
  - **Проблема:** Один пошкоджений запис у `localStorage` обриває весь цикл пошуку бренду.
  - **Рішення:** Обгорнути `JSON.parse` всередині циклу ітерації по `localStorage` окремим блоком `try-catch { continue; }`.

- [ ] **[H3] Stale Closures у `studio_events.ts` (Кнопки копіюють дані попереднього коментаря)**
  - **Файл:** [studio_events.ts](file:///d:/Chrome%20Extension/Время%20перемен.%20Chrome%20Extension/streamyars-copy-buttons%20(added%20checkbox)%200.6-2026.01.11/youtube/studio/studio_events.ts#L190-L280)
  - **Проблема:** Через `dataset.syhBound = 'true'` та Polymer virtual scrolling (`iron-list`) замикання зберігають застарілі `author` і `text`.
  - **Рішення:** Зчитувати `author` та `text` з `threadEl` динамічно безпосередньо у момент кліку по кнопці.

- [ ] **[H4] `eval()` у `stats_exporter.ts` (Порушення CSP Chrome Web Store)**
  - **Файл:** [stats_exporter.ts](file:///d:/Chrome%20Extension/Время%20перемен.%20Chrome%20Extension/streamyars-copy-buttons%20(added%20checkbox)%200.6-2026.01.11/modules/stats_exporter.ts#L165)
  - **Проблема:** Динамічне завантаження Chart.js через `fetch` + `eval()` блокується Manifest V3 CSP під час публікації в Chrome Web Store.
  - **Рішення:** Імпортувати Chart.js через бандлер Vite або додати як статичний файл через `web_accessible_resources`.

- [ ] **[H5] 35+ глобальних функцій на `window` у popup-скриптах**
  - **Файли:**
    - [popup_init.js](file:///d:/Chrome%20Extension/Время%20перемен.%20Chrome%20Extension/streamyars-copy-buttons%20(added%20checkbox)%200.6-2026.01.11/popup/popup_init.js)
    - [popup_telegram.js](file:///d:/Chrome%20Extension/Время%20перемен.%20Chrome%20Extension/streamyars-copy-buttons%20(added%20checkbox)%200.6-2026.01.11/popup/popup_telegram.js)
    - [popup_prayers.js](file:///d:/Chrome%20Extension/Время%20перемен.%20Chrome%20Extension/streamyars-copy-buttons%20(added%20checkbox)%200.6-2026.01.11/popup/popup_prayers.js)
  - **Проблема:** Забруднення глобального `window` об'єкта (понад 35 функцій), що перешкоджає ізольованому тестуванню та tree-shaking.
  - **Рішення:** Поетапна міграція popup-скриптів на ES-модулі (`import/export`) та TypeScript.

## 🟠 MEDIUM — Архітектурні проблеми

- [ ] **[M1] Відсутність перевірок `chrome.runtime.lastError` у popup callbacks**
  - **Файли:** `popup/popup_init.js`, `popup/popup_telegram.js`, `popup/popup_prayers.js`
  - **Проблема:** При оновленні розширення операції зі storage мовчки провалюються без логування помилки.
  - **Рішення:** Додати перевірку `if (chrome.runtime.lastError)` в усі callbacks для `chrome.storage.local.get/set`.

- [ ] **[M2] Popup-скрипти обходять адаптер `SYH_STORAGE` (42+ прямих виклики `chrome.storage.local`)**
  - **Файли:** `popup_init.js` (17 викликів), `popup_telegram.js` (9 викликів), `popup_prayers.js` (16 викликів)
  - **Проблема:** Прямі звернення до storage блокують можливу міграцію API та порушують єдину точку правди.
  - **Рішення:** Перевести всі прямі виклики storage у popup на централізований адаптер `SYH_STORAGE` (за аналогією з `options.ts`).

- [ ] **[M3] Нескінченний `setInterval(1000)` у SPA навігації без cleanup**
  - **Файл:** [studio_content.ts](file:///d:/Chrome%20Extension/Время%20перемен.%20Chrome%20Extension/streamyars-copy-buttons%20(added%20checkbox)%200.6-2026.01.11/youtube/studio/studio_content.ts#L45-L65)
  - **Проблема:** `checkPathChange` опитує сторінку щосекунди і не очищується при зупинці модуля.
  - **Рішення:** Зберігати `pollInterval` ID та очищувати через `clearInterval` у `stopModule()`.

- [ ] **[M4] Плоска структура ключів storage без неймспейсінгу та збереження raw HTML**
  - **Файли:** `popup/popup_telegram.js`, загальний storage schema
  - **Проблема:** Збереження HTML-рядків (`tg_finalResultHtml` тощо) та відсутність ієрархії ключів роздувають storage.
  - **Рішення:** Запровадити неймспейси (наприклад `syh:popup:telegram:vp_ss`) та зберігати тільки структуровані JSON-дані замість raw HTML.
