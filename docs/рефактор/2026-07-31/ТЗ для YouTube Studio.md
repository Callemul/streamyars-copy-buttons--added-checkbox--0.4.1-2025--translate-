# ТЗ: Оновлення розширення (Telegram та YouTube Studio)

## 1. Зміни в попапі (Telegram вкладка)
Контент всередині вкладки Telegram тепер має бути поділений на 4 клоновані аркуші (напрямки):
1. "Время перемен СШ"
2. "Опарин проповеди"
3. "Молчанов СШ"
4. "Молчанов проповеди"
В кожному аркуші є спеціально виділене місце для зберігання питань та молитов, доданих з YouTube.

## 2. Зміни старого модуля YouTube
- В налаштуваннях розширення додати галочку для повного вимкнення старого модуля.
- Старий модуль тепер має працювати **ЛИШЕ** на двох YouTube-каналах (раніше працював на всіх).

## 3. Новий модуль: YouTube Studio
Створити окремий content_script для YouTube Studio, який активується **тільки** якщо URL містить `/comments/` (наприклад: `https://studio.youtube.com/channel/.../comments/inbox...`).

### 3.1. Логіка розпізнавання каналу та категорії
Система повинна автоматично визначати поточний канал та категорію відео (по назві відео), щоб знати, в який з 4-х аркушів відправляти коментарі:

**Канал "Время перемен":**
- Якщо в назві відео є "СУББОТНЯЯ ШКОЛА" ➔ аркуш `"Время перемен СШ"`.
- Якщо в назві є "Опарин" ➔ аркуш `"Опарин проповеди"`.

**Канал "Слово живое":**
- Якщо в назві відео є "СУББОТНЯЯ ШКОЛА" ➔ аркуш `"Молчанов СШ"`.
- Всі інші відео на цьому каналі (виключення) ➔ аркуш `"Молчанов проповеди"`.

*(Технічна деталь для розробника: Назву каналу беремо з елемента `#entity-label-container #entity-name` в лівому сайдбарі, або ж як альтернатива — можна прив'язуватись до унікального ID каналу з URL `window.location.pathname`).*

### 3.2. Інтерфейс під коментарями (UI)
YouTube Studio підвантажує коментарі динамічно (це SPA), тому обов'язково використовуй `MutationObserver`. 
Біля кожного коментаря (в блок `.ytcp-comment-action-buttons #toolbar`) треба додавати 3 кнопки (в стилі кнопок з StreamYard):
1. Копіювати (копіює в буфер обміну: `Автор + Текст коментаря`).
2. Додати до питань (відправляє коментар у відповідний аркуш в попапі).
3. Додати до молитов (відправляє коментар у відповідний аркуш в попапі).

**Взаємодія з кнопками (тільки для "Питань" та "Молитов"):**
- При натисканні на додавання до питань/молитов іконка кнопки змінюється на зелену галочку (означає, що дію виконано).
- **Tooltips:** 
  - На звичайній кнопці: "Додати до [Назва визначеного аркуша] - [питань/молитов]".
  - На зеленій галочці: "Відправлено до [Назва аркуша] - [питань/молитов]".

### 3.3. Badge (Ярлик категорії) під відео
Під заголовком відео (`#video-title`) біля кожного коментаря має з'являтися невеликий Badge з назвою визначеного аркуша (куди підуть питання/молитви з цього відео).
- Якщо автоматично визначити категорію по назві не вдалося, Badge пише "Категорію не визначено".
- На Badge можна натиснути — відкривається випадаючий список (Dropdown), де адмін може вручну обрати один з 4-х аркушів для цього конкретного відео.

### 3.4. Збереження стану (Persistent Storage)
- **Стан кнопок (зелені галочки):** Натиснуті кнопки мають запам'ятовуватись назавжди в `chrome.storage.local`. 
  - **Унікальний ключ коментаря (тройна зв'язка):** `Назва відео + Ім'я автора + Текст коментаря`.
- **Ручний вибір категорії відео:** Зв'язок "Відео ➔ Вибраний аркуш" також запам'ятовується назавжди. 
  - **Ключ для відео:** Якщо у відео є посилання (`href`), використовуємо його, якщо немає — використовуємо текстову назву відео. 
  Усі майбутні коментарі під цим відео будуть автоматично маршрутизуватись у вибраний адміном аркуш.

## 4. Приклади HTML структури сторінки

**Назва каналу:**
```html
<div id="entity-label-container" class="style-scope ytcp-navigation-drawer">
  <div id="entity-name" class="entity-name style-scope ytcp-navigation-drawer">Олександр І.</div>
</div>
```

**Список коментарів та назва відео:**
```html
<div id="comments-content" class="style-scope ytcp-activity-section">
  <ytcp-comments-section id="comments-section">
    <tp-yt-iron-list id="iron-list">
      <div id="items" role="list">
        <!-- Шаблон одного коментаря в списку (повторюється) -->
        <div class="ytcp-comment-thread style-scope ytcp-comments-section">
          <ytcp-comment-thread>
            <ytcp-comment id="comment">
              <div id="row-container">
                <div id="comment-row">
                  <div id="body">

                    <!-- Автор коментаря -->
                    <div id="author-thumbnail">
                      <a id="avatar">...</a>
                    </div>
                    <div id="content">
                      <div id="metadata">
                        <a id="name">
                          <yt-formatted-string class="author-text">@ІринаМережко</yt-formatted-string>
                        </a>
                        <yt-formatted-string class="published-time-text">3 тижні тому</yt-formatted-string>
                      </div>

                      <!-- Текст коментаря -->
                      <span id="expander-container">
                        <span id="expander">
                          <yt-formatted-string id="content-text">Текст коментаря...</yt-formatted-string>
                        </span>
                      </span>

                      <!-- Панель кнопок (сюди додаються кнопки плагіна) -->
                      <div id="comment-actions">
                        <ytcp-comment-action-buttons id="action-buttons">
                          <div id="toolbar">
                            <!-- Кнопки YouTube Studio -->
                          </div>
                        </ytcp-comment-action-buttons>
                      </div>
                    </div>

                    <!-- Назва відео для аналізу напрямку -->
                    <ytcp-comment-video-thumbnail id="video-thumbnail">
                      <a id="body">
                        <div id="video-title">
                          <yt-formatted-string class="style-scope ytcp-comment-video-thumbnail">
                            Дитяче християнське караоке. Море благословень. Мінус. I'm so Blessed
                          </yt-formatted-string>
                        </div>
                      </a>
                    </ytcp-comment-video-thumbnail>

                  </div>
                </div>
              </div>
            </ytcp-comment>
          </ytcp-comment-thread>
        </div>
      </div>
    </tp-yt-iron-list>
  </ytcp-comments-section>
</div>
```
