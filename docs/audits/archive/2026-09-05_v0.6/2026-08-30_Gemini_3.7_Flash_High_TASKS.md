### [TASK-W1-01] 🔴 YouTube Studio Channel Gate: повна ізоляція сторонніх каналів
- **Мета:** Заблокувати роботу модуля, ін'єкцію кнопок/чекбоксів у коментарі та рендер баджа в шапку при перегляді YouTube Studio на будь-якому неавторизованому каналі (`channelKey === 'unknown'`).
- **Модель:** `gpt-5.6-sol` / `Gemini 3.7 Flash (High)`
- **Reasoning:** `xhigh`
- **Режим:** `workspace-write`
- **Owned files:**
  - `youtube/studio/studio_content.ts`
  - `youtube/studio/studio_comment_processor.ts`
  - `youtube/studio/studio_header_counters.ts`
  - `youtube/studio/studio_adapter.ts`
  - `tests/studio_channel_gate.test.js` (або відповідний тест сьют)
- **Заборонені файли:** `youtube/studio/studio_selectors.ts`, файли поза `youtube/studio/`
- **Залежності:** Немає
- **Evidence з аудиту:** Розділ 3, [Area 3] Знахідка 1. `getStudioChannelInfo().key === 'unknown'` рендерить бадж "Канал не розпізнано", ін'єктує кнопки та записує коментарі сторонніх каналів у `SHEET_IDS.VP_SS` (`vp_ss`).
- **Acceptance criteria:**
  1. Якщо `!isAllowedChannelKey(channelKey)`, `StudioCommentProcessor.startModule()` негайно викликає `stopModule()` і не ін'єктує жодного DOM-вузла.
  2. Бадж "Канал не розпізнано" видалено; шапка Studio залишається незайманою.
  3. `StudioCommentAdapter.getSheetId()` не здійснює мовчазний fallback на `vp_ss` для невідомих каналів.
  4. При SPA-переході на дозволений канал модуль активується; при переході на сторонній канал — повністю очищає UI.
- **Команди перевірки:** `npm run test && npm run lint`
- **Що повернути:** Змінені файли, результати тестів гейта Studio, верифікацію ідемпотентності очищення.
