# StreamYard Helper (Chrome Extension)

Браузерне розширення (Chrome Extension) для платформ **StreamYard**, **YouTube** та **YouTube Studio**. Призначене для автоматизації роботи ведучих і модераторів трансляцій: збір та структурування коментарів, інтерактивне керування банерами, фіксація молитовних запитів та розширена аналітика ефірів.

## Основні можливості

- **StreamYard**: Ін'єкція кнопок копіювання, керування чекбоксами для банерів та коментарів, моніторинг активності та інтерактивні елементи керування студією.
- **YouTube & YouTube Studio**: Збір та моніторинг коментарів у реальному часі під час трансляцій та прем'єр, адаптери для роботи з віртуалізованим рециклінгом `<iron-list>`.
- **Молитовні запити**: Структурований облік молитовних запитів зі збереженням локацій авторів, групування, фільтрація та експорт.
- **Банери та категорії**: Інтелектуальний парсер банерів з підтримкою категорій (молитва, суботня школа/урок, запитання слухачів) та очисткою суфіксів авторів.
- **Аналітика ефірів**: Детальні метрики (Min, Max, Median, Avg) для кожного блоку трансляції з візуалізацією графіків за допомогою Chart.js та можливістю генерації звітів і слайдів.

## Технологічний стек

- **Мова**: [TypeScript](https://www.typescriptlang.org/)
- **Збирач / Баундлер**: [Vite](https://vitejs.dev/) (@crxjs/vite-plugin)
- **Архітектура розширення**: Chrome Manifest V3 (Service Worker, Content Scripts, Popup, Options UI)
- **Графіки та візуалізація**: [Chart.js](https://www.chartjs.org/)
- **Тестування**: Вбудований тестовий раннер Node.js з [happy-dom](https://github.com/capricorn86/happy-dom)
- **Лінтер та перевірка типів**: ESLint, TypeScript Compiler (`tsc`)

## Інструкції та команди

### Встановлення залежностей
```bash
npm install
```

### Режим розробки
```bash
npm run dev
```

### Збірка розширення (Production build)
```bash
npm run build
```
Зібране розширення формується у папці `dist/`. Його можна завантажити в Google Chrome через сторінку `chrome://extensions` (активувати «Режим розробника» -> «Завантажити розпаковане розширення» -> обрати папку `dist`).

### Запуск тестів
```bash
# Запуск повного набору тестів
npm run test

# Запуск YouTube тестів
npm run test:youtube

# Запуск YouTube Studio тестів
npm run test:studio

# Тести з покриттям коду
npm run test:coverage
```

### Лінтування коду
```bash
npm run lint
```

### Перевірка типів TypeScript
```bash
npm run typecheck
```

## Структура папок

- **`main.ts`** — Головна точка входу контентного скрипта для платформи StreamYard (`streamyard.com`).
- **`modules/`** — Бізнес-логіка розширення: адаптери студії, парсери банерів, сховище даних (`storage`), аналітика, робота з молитовними записами, фільтри та утиліти.
- **`popup/`** — Інтерфейс та логіка спливаючого вікна розширення (Popup UI): перегляд коментарів, молитовних запитів, статистика та експорт.
- **`options/`** — Сторінка налаштувань розширення (налаштування категорій, тайм-аутів, параметрів збереження тощо).
- **`youtube/`** — Модулі контентних скриптів та стилів для звичайного перегляду YouTube (`youtube.com`).
- **`youtube/studio/`** — Спеціалізовані адаптери, ін'єкції та спостерігачі для творчої студії YouTube (`studio.youtube.com`).
- **`background/`** — Фоновий сервіс-воркер (`service-worker.ts`) Manifest V3 для координації вкладок, обробки повідомлень та фонових задач.
- **`tests/`** — Автоматизовані тести (компонентні та модульні тести для парсерів, сервісів збереження, селекторів та аналітики).

### Повна перевірка перед комітом
```bash
npm run verify
```
Послідовно виконує `typecheck` → `lint` → `test` → `build`.
